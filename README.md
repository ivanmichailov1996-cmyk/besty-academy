# Besty Academy

Обучающая веб-платформа Besty: библиотека материалов по разделам + тесты после уроков.
Публичный доступ, без авторизации. Next.js (App Router) + TypeScript + Tailwind CSS,
статическая сборка — не требует сервера/базы данных.

## Быстрый старт

```bash
npm install
npm run dev       # локальная разработка, http://localhost:3000
npm run build     # статическая сборка -> папка out/
```

Готовую папку `out/` можно захостить где угодно: Vercel, Cloudflare Pages, Netlify,
GitHub Pages или обычный статический хостинг/Nginx.

## Структура контента

Все материалы — в `src/content/`:

- `src/content/types.ts` — типы: `Section`, `Lesson`, `ContentBlock`, `QuizQuestion`.
- `src/content/sections.ts` — разделы платформы и список уроков в каждом (карта сайта).
- `src/content/lessons/*.ts` — контент готовых уроков (заголовки, списки, примеры фраз,
  таблицы, тесты).

### Как добавить новый урок

1. Создать объект `Lesson` в `src/content/lessons/<имя>.ts` — переписать контент
   исходного PPTX/PDF/DOCX в массив `blocks` (`heading`, `paragraph`, `list`, `steps`,
   `phrases`, `callout`, `table`) и добавить 3–5 вопросов в `quiz`.
2. Добавить урок в нужный раздел в `src/content/sections.ts` (или заменить
   `placeholder(...)` на готовый урок с `ready: true`).
3. `npm run build` — страница и статический маршрут создадутся автоматически
   (см. `generateStaticParams` в `src/app/[section]/[lesson]/page.tsx`).

Подробная пошаговая инструкция для нетехнического редактирования (с примерами
каждого вида блока, добавлением целого нового раздела и разбором частых
ошибок) — в файле [`КАК_МЕНЯТЬ_КОНТЕНТ.md`](./КАК_МЕНЯТЬ_КОНТЕНТ.md).

Урок с `ready: false` (плейсхолдер) автоматически показывается в разделе как
карточка со статусом «скоро» — так исходная библиотека материалов уже полностью
отражена в навигации сайта, даже пока не весь контент переверстан.

## Полнота контента (проверка на соответствие первоисточникам)

Каждый урок был построчно сверен с полным текстом исходной презентации/документа —
это второй проход после первичной перевёрстки, специально чтобы ничего не потерялось
при первой транскрипции. В ходе сверки нашли и исправили реальные пробелы:

- часть текста в PPTX хранится не в обычных текстовых полях, а в SmartArt-графике
  (отдельный XML внутри файла) — стандартное извлечение текста его не видит; такой
  текст нашли отдельно и перенесли в уроки (например, алгоритм кассира в «Приём и
  оплата на прилавке», часть контента в «Сервис как культура»);
- один PDF (`Сервис Besty.pdf`) извлекался с искажённым текстом из-за особого шрифта —
  распознали через OCR;
- карта обучений (`Копия Карта обучений.xlsx`) при первой сверстке была вытащена не
  полностью — пересобрали таблицу по дням заново из полного дампа файла, заодно
  поправили два дня, в которые попал не тот модуль (десерты кафе относятся к Дню 5,
  а не Дню 4; сертификация — к Дню 6, а не Дню 5);
- убрали одну картинку-заглушку со сторонним водяным знаком (использовалась вместо
  реального фото со станции).

Также довели до полного текста (не сокращённого пересказа) уроки по гриль-станции,
фритюру, качеству, завтракам, сбору и выдаче на прилавке, техникам продаж, психологии
гостей, посуде и сервировке, памятке кассиру, гостевым скриптам, 6 принципам сервиса,
всей программе обучения менеджеров, семинару для наставников, всем 6 КЛН-справочникам
и обучающим карточкам.

## Публикация на GitHub Pages (публичная ссылка)

Сайт можно опубликовать по постоянной публичной ссылке `https://<ваш-логин>.github.io/besty-academy/`
через GitHub Pages — репозиторий `.github/workflows/deploy.yml` уже настроен: при каждом
`git push` в ветку `main` GitHub сам собирает сайт (`npm ci && npm run build` с
`NEXT_PUBLIC_BASE_PATH=/besty-academy`) и публикует папку `out/`.

Видео (~330 МБ суммарно) в архив с исходниками не входят — их нужно скопировать в
`public/videos/` из папки `D:\BESTY\Обучение\Видео` (это делают автоматически оба скрипта
публикации ниже). Каждый файл видео (30–52 МБ) укладывается в лимит GitHub на размер файла
(100 МБ) без Git LFS.

Публикацией занимаются два отдельных файла — они делают разные вещи, важно не перепутать:

- **`ОБНОВИТЬ_ОТ_CLAUDE.bat`** — берёт актуальный `besty-academy.zip` (архив с исходным
  кодом сайта, который присылает Claude), обновляет им папку `besty-academy-github` и сразу
  публикует результат. Именно этим скриптом нужно пользоваться, чтобы получить на сайте новую
  версию после того, как Claude что-то изменил в коде/контенте.
- **`ОПУБЛИКОВАТЬ_НА_GITHUB.bat`** — публикует то, что прямо сейчас лежит в папке
  `besty-academy-github`, ничего не переустанавливая. Им пользуются, если правите файлы сами,
  вручную, прямо в этой папке (см. `КАК_МЕНЯТЬ_КОНТЕНТ.md`).

Что нужно сделать один раз:

1. Создать пустой публичный репозиторий на GitHub с именем `besty-academy` (без README и
   .gitignore).
2. Запустить `ОБНОВИТЬ_ОТ_CLAUDE.bat` — он распакует исходники, скопирует видео и спросит
   ссылку на репозиторий, после чего сделает `git push`. Первый пуш попросит войти в GitHub
   в браузере (стандартное окно Git Credential Manager).
3. В репозитории на GitHub: Settings → Pages → Build and deployment → Source →
   **GitHub Actions**.
4. Через 1–2 минуты сайт будет доступен по адресу `https://<ваш-логин>.github.io/besty-academy/`.

Дальнейшие обновления от Claude публикуются повторным запуском `ОБНОВИТЬ_ОТ_CLAUDE.bat`
(если в папке были несохранённые ручные правки, скрипт сам сохранит их в историю Git отдельным
коммитом перед обновлением, чтобы они не потерялись). Собственные ручные правки публикуются
через `ОПУБЛИКОВАТЬ_НА_GITHUB.bat`.

## Дизайн

- Фирменный цвет Besty: `#FFB800`, вторичный акцент `#7A2138` (см. `src/app/globals.css`,
  токены `--brand*` / `--accent*`).
- Системный шрифт (без внешних подключений — важно для лёгкости и офлайн-сборки). Крупные
  заголовки — системный serif-стек (`.font-display` в `globals.css`), мелкие ярлычки —
  разрядка прописными (`.label-eyebrow`) — ориентир: референс дизайна mymind.
- Пастельные поверхности карточек без рамок и теней (`bg-surface-amber` / `-blush` / `-sage`),
  построены на фирменных цветах Besty.
- Анимации: контент на статичных страницах появляется с лёгким «наплывом» на кривой
  `cubic-bezier(0.19, 1, 0.22, 1)` за 0.7 с (классы `.pop-in` / `.stagger` в `globals.css`);
  на длинной странице Welcome-курса те же классы включаются по прокрутке через
  `IntersectionObserver` (`.reveal`, хук `useScrollReveal` в `WelcomeCourse.tsx`). Наводки на
  карточки/кнопки — быстрый отклик 0.2 с. Уважает `prefers-reduced-motion`.
- Мобильная адаптивность — приоритет.

## Прогресс тестов

Результаты тестов сохраняются в `localStorage` браузера (без сервера и авторизации) —
у каждого урока показывается лучший результат на этом устройстве.
